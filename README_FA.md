# SEN SPORT PWA — بسته آماده میزبانی

این بسته فایل‌های اولیه PWA را دارد (manifest، service worker و آیکون‌ها). برای نصب به‌عنوان اپلیکیشن، باید سایت روی HTTPS منتشر شود.

## انتشار رایگان با GitHub Pages
1. در GitHub یک Repository جدید بسازید (مثلاً `sen-sport`).
2. فایل‌های همین پوشه را در ریشه Repository آپلود کنید.
3. Settings → Pages → Deploy from a branch → `main` و `/ (root)` → Save.
4. پس از فعال شدن Pages، لینک سایت را باز کنید.

## نصب روی گوشی
- Android/Chrome: لینک سایت را باز کنید → منوی سه‌نقطه → Install app یا Add to Home screen.
- iPhone/Safari: لینک را باز کنید → Share → Add to Home Screen.

## محدودیت
این PWA فعلاً نمونه آزمایشی/پوسته است. ورود واقعی، ذخیره امن اطلاعات، مدیریت تیم آنلاین و همگام‌سازی چند کاربر نیاز به بک‌اند و توسعه جداگانه دارد. فایل‌ها را به‌تنهایی در گوشی نصب نکنید؛ باید روی HTTPS میزبانی شوند.
