# راه‌اندازی اتصال آنلاین SEN SPORT (فارسی)
## وضعیت
داشبورد فعلی همین الان در GitHub Pages قابل استفاده است، اما داده‌هایش فقط در همان مرورگر (localStorage) ذخیره می‌شود. این فایل‌ها زیرساخت اتصال امن آنلاین را آماده می‌کنند؛ بدون ساخت پروژه Supabase و واردکردن کلید عمومی پروژه، ورود آنلاین فعال نیست.

## ۱) ساخت پروژه
1. در https://supabase.com یک پروژه بسازید.
2. از Project Settings → API، Project URL و کلید **anon/public** را بردارید.
3. هرگز کلید service_role را در سایت یا GitHub قرار ندهید.

## ۲) ساخت جداول
SQL فایل schema.sql را در Supabase → SQL Editor اجرا کنید.
برای راه‌اندازی اولیه تیم و مربی، باید از پنل امن Supabase یک team و profile مربی ایجاد شود؛ نقش coach را به ثبت‌نام عمومی واگذار نکنید.

## ۳) آدرس استفاده فعلی
داشبورد: https://hessarimehrdad-sys.github.io/Sen_sport/sen-sport-dashboard.html
- پنل مربی: رمز اولیه 1234 (فقط قفل نمایشی مرورگر است؛ امنیت واقعی حساب کاربری نیست).
- اطلاعات این نسخه بین دستگاه‌ها همگام نمی‌شود؛ پاک‌کردن داده مرورگر ممکن است اطلاعات را حذف کند.
- برای داده واقعی بازیکنان، از اطلاعات حساس در نسخه محلی/عمومی استفاده نکنید تا اتصال Auth و Storage امن تکمیل شود.

## مراحل بعد از ساخت پروژه
Project URL و anon/public key را برای پیکربندی فرانت‌اند لازم داریم. این کلید عمومی است؛ service_role ممنوع.
